# Erreur

Oh non, vous avez rencontré une erreur dans GB Studio...

Avant toute chose, vous devriez faire une sauvegarde de votre dossier de projet, au cas où quelque chose se passerait mal.

Une fois la sauvegarde effectuée, vous pourrez toujours sauvegarder votre projet via le menu `Fichier / Enregistrer`. Si cela échoue, réutilisez la sauvegarde éffectuée précédement.

## Signaler un problème

Si vous avez rencontré une erreur dans GB Studio, il serait très apprécié que vous la signaliez à l’adresse suivante :
https://github.com/chrismaltby/gb-studio/issues

## Obtenir de l’aide

Les meilleurs endroits pour obtenir de l’aide lorsque GB Studio ne fonctionne pas sont le [serveur Discord](https://discord.gg/bxerKnc) ou le subreddit [/r/GBStudio](https://www.reddit.com/r/gbstudio).
